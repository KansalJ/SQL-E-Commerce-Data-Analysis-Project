This project focuses on building a Data Model using PostgreSQL, Python

## About the Dataset/API
I worked with the Instacart Market Basket Analysis dataset, which provided a rich and complex structure to explore real-world business insights.
Dataset - https://www.kaggle.com/datasets/psparks/instacart-market-basket-analysis

## Tools Used
- **pgAdmin:** For accessing the PostgreSQL server and performing data analytics and data modeling. 
- **Jupyter Notebook:** For writing the python code to execute the whole pipeline.

## Dependencies
Install the required Python packages:

```bash
pip install psycopg2
```
